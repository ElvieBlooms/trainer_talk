TRAINER TALK -- BUILD YOUR OWN VOICE PACK
=============================================
A plain-English guide to what each sound file is for, so you can record
or source your own lines and drop them in -- no code editing required.

THE EASY ROUTE: THE PACKAGER
---------------------------------
Everything below can be done by hand, but there's a faster way: the
Trainer Talk Packager (https://github.com/ElvieBlooms/trainer_talk_packager)
takes a zip of audio clips, transcribes them, and helps you match each
one to an event -- then exports a pack folder shaped exactly like the
ones this guide describes, ready to drop into assets/characters/ or
assets/milestones/. It reads this mod's own schema.json for the
current event list, so it won't drift out of date the way a
hand-typed guide can. See that repo's NEEDED_ZIPS.md for which zip(s)
a given recipe expects.

WHERE TO GET AUDIO
-----------------------
Starting with the Hoenn release, this mod ships without bundled voice
packs -- the packager is the intended way to build one from your own
source audio. https://sounds.spriters-resource.com/ is a long-running,
community-run archive of ripped game audio that's a common starting
point for this kind of thing. This project has no affiliation with
that site, doesn't control what it hosts, and can't promise any
specific page stays up -- it's mentioned here as a pointer, not an
endorsement, and it's on you to check what you're allowed to do with
anything you download from anywhere.

HOW THIS WORKS
------------------
Every voice line lives in a folder under assets/characters/ -- kris/
and jessie/ are the two that ship with the mod. CHARACTER discovers
whatever folders actually exist there automatically, so you don't even
need to replace an existing one: just create a new folder (any name)
under assets/characters/, drop your own recordings in using the same
filenames as the list below, and it shows up as a real CHARACTER
option next time the mod loads -- genuinely no code editing required,
for a brand new character slot or a replacement either one.

An optional meta.json inside your folder sets the display name, e.g.:
  { "label": "MY CHARACTER" }
Without one, the folder name itself (uppercased) is used instead, so
it's worth adding one if the folder name isn't meant to be read
directly as the label.

You don't need to fill in every single file below to get started --
anything missing just stays quietly silent for that one moment,
nothing breaks. Build it out gradually if you'd rather.

TWO THINGS WORTH KNOWING BEFORE THE LIST
---------------------------------------------
- Numbered files (hit1.ogg, hit2.ogg, hit3.ogg, etc.) are NOT a
  sequence -- they're alternates. The game picks one at random each
  time. You only need one to make that moment work at all; add a 2nd
  or 3rd later purely for variety if you want it to feel less
  repetitive.
- "E4" means Elite Four (the four powerful trainers you face right
  before the Champion) -- it's the only abbreviation used anywhere in
  these filenames.

DAY & NIGHT
===============
Quiet, ambient lines -- nothing's happening in battle, it's just a
moment of time passing while you play. Gen 1 games have no real
day/night clock, so these mostly only come up on a Gen 2 save.

NOT PART OF A CHARACTER PACK -- THE MILESTONES FOLDER
===========================================================
You shouldn't need to touch this for a custom character. When you
actually BEAT a gym leader, Elite Four member, or the Champion, the
congratulations line comes from a separate folder (assets/milestones/)
instead of your character folder -- that's intentional, so the
leader's own voice (or a stadium announcer) can celebrate the win
regardless of which character voice you've picked for everything else.
There's already a toggle for choosing between packs there, in the
Mods manager.

These are separate, static events from a character pack's everyday
lines -- but they follow the exact same drop-a-folder rule as
CHARACTER above, entirely independently of building a character pack
at all. If you wanted to add a third milestone voice option (a
different announcer, say), that's just a new folder under
assets/milestones/ with its own meta.json label, discovered the same
way -- nothing about it depends on or interferes with whatever's in
assets/characters/.
